# Unified Platform Architecture

The unified Busy Bee Holdings LLC repository is organized into three layers:

1. `src/busy_bee/` — imported Busy Bee V2 application and services
2. `src/busy_bee_holdings_llc/` — governance, cap table, legal integration, and platform wrapper
3. `vendor/` + `imports/` — preserved source provenance and upstream import targets

The human user remains the approval authority for real financial execution.
